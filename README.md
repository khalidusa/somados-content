# سومادوس — نظام المحتوى اليومي

ينتج ويجدول تلقائياً، كل يوم وإلى الأبد، بلا حاسوب مفتوح:

| الموعد (بغداد) | المحتوى | المقاس | المنصات |
|---|---|---|---|
| 10:00 | صورة | 1080×1350 | فيسبوك · انستغرام |
| 19:00 | ريل 10 ثوانٍ بموسيقى | 1080×1920 | فيسبوك · انستغرام |

بغداد وإسطنبول كلتاهما UTC+3 ثابت بلا توقيت صيفي، فجدول واحد يخدم السوقين.
الكلفة المستهدفة: **صفر دولار شهرياً**.

## البنية

```
src/schedule.js    التوقيت — الإزاحة تُقرأ من tzdata لا مكتوبة كثابت
src/matrix.js      المصفوفة — 88,128 تركيبة، مجدول متسلسل يضمن التغطية والتباعد
src/copy.js        النصوص والهاشتاكات + فترة تبريد 120 يوم + حارس الأسعار والهواتف
src/design.js      قالب HTML بخط Tajawal مدموج base64
src/render.js      لقطات Chromium — about:blank قبل كل مستند، وقياس بعد جاهزية الخط
src/reel.js        إطارات من window.__seek(t) + تجميع FFmpeg + تحقق ffprobe
src/cloudflare.js  توليد الخلفيات — FLUX-1-schnell
src/buffer.js      قراءة القنوات والطوابير والجدولة
src/music.js       اختيار المقاطع وقياسها
src/state.js       الحالة تُحفظ بعد كل منشور — الفشل لا يضيّع ما أُنجز
```

## التشغيل المحلي

```bash
npm ci
npm test                                          # التوقيت + المصفوفة + النصوص
node scripts/generate.js --days 5 --placeholder   # الخط كاملاً بلا مفتاح ولا صرف حصة
node scripts/build-review.js                      # صفحتا المراجعة
open content/index.html
```

## المفاتيح

انسخ `.env.example` إلى `.env` واملأه. نفس الأسماء تُوضع بـ **Settings ← Secrets and variables ← Actions**.

| Secret | من وين |
|---|---|
| `CF_ACCOUNT_ID` · `CF_API_TOKEN` | dash.cloudflare.com ← AI ← Workers AI ← Use REST API (الصلاحيتان Read و Edit معاً) |
| `BUFFER_ACCESS_TOKEN` | publish.buffer.com/settings/api ← New Key (صلاحية سنة — ضع تنبيهاً بعد 11 شهراً) |
| `MUSIC_TOKEN` | fine-grained PAT بصلاحية قراءة على مستودع الموسيقى الخاص |

| Variable | القيمة |
|---|---|
| `PAGES_BASE_URL` | رابط GitHub Pages — **ليس** `raw.githubusercontent` (يرجع 429 للروابط الخارجية) |
| `MUSIC_REPO` | `<user>/somados-audio` |
| `DECLARE_AI_GENERATED` | `true` للتصريح لميتا. اتركه فارغاً لعدم التصريح — **لا تضع `false`**، إرسال false تصريح كاذب |

## ليش الموسيقى بمستودع خاص

رخصة Pixabay تمنع إعادة توزيع الملف الصوتي **كملف مستقل**. الفيديو الذي يحتوي الموسيقى
استعمال مسموح؛ رفع الـMP3 الخام لمستودع عام هو إعادة توزيع. لذلك الموسيقى بمستودع خاص
تُسحب وقت التشغيل فقط، ولا تصل للمستودع العام أبداً.

## التشغيل الشهري

1. مرة بالشهر: تبويب **Actions** ← «توليد المحتوى الشهري» ← Run workflow. هذا كل شي.
2. اختيارياً: افتح صفحة المراجعة لتشوف الشهر الجاي بصوره ونصوصه.
3. مرة بالسنة: جدّد مفتاح Buffer.
4. عند تغيير كلمة مرور فيسبوك أو انستغرام: أعد ربط القناة من واجهة Buffer.

## قواعد لا تُكسر

- **لا أسعار ولا أرقام هاتف** بأي نص. محمية بحارس بنيوي (`assertClean`) ومعه ضابطان موجبان بالاختبار.
- **لا إقامات تركية** بأي محتوى — مستبعدة بقرار المالك.
- **لا شعارات شركات طيران ولا نص مقروء** داخل الصورة المولّدة. المنع بالتأطير القريب لا بالفلترة:
  ما فيه ولا مشهد يصف طائرة كاملة.
- **لا مباني دينية** بمشهد النجف.
- **لا يُنشر محتوى `placeholder: true`** — معبّئ الطابور يرفضه بنيوياً.
- المستودع `khalidusa/somados` هو **الموقع الحي**. هذا المشروع لا يلمسه.

## أعطال معروفة ومحلولة داخل الكود

| العطل | مكان الحل |
|---|---|
| الموديل يرفض `seed`/`width`/`height`/`negative_prompt` | `cloudflare.js` — `prompt` و`steps` فقط |
| الحصة تُجدَّد بنافذة متحركة 24 ساعة لا منتصف الليل | `cloudflare.js` — `spentLast24h` |
| إعادة المحاولة تبتلع خطأ النفاد | `DailyQuotaExhausted.fatal` يُعاد رميه فوراً |
| `scrollHeight` داخل flex يكذب — العنصر ينكمش بدل أن يفيض | `design.js` — قياس هندسي لموضع الفوتر |
| القياس قبل `document.fonts.ready` يقرأ الخط الاحتياطي | `render.js` — `__fitText()` بعد جاهزية الخط |
| السهم `←` داخل نص عربي يقلب اتجاهه بصرياً | `design.js` — «من … إلى» بدل السهم |
| `translateY` من `__seek(0)` يخدع حارس التصغير | `design.js` — القياس بالحالة النهائية |
| سيرفرات GitHub بلا `ffprobe` | `generate.yml` — `apt-get install ffmpeg` |
| فشل قياس المقطع ≠ قِصَره | `music.js` — يُبقى ويُطبع السبب |
| `posts` يرجع 10 بلا `first` فيُقرأ الطابور ناقصاً | `buffer.js` — ترقيم كامل بـ`pageInfo` |
| workflowان يرفعان لنفس الفرع | `concurrency: content-write` + إعادة ترتيب 5 مرات |
| GitHub يعطّل الجداول بعد 60 يوماً | نبضة commit كل تشغيل |
