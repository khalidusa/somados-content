# محرك محتوى سومادوس

ينتج **صورة إعلانية كل يوم 10:00** و**ريل ١٠ ثوانٍ كل يوم 19:00** (بتوقيت بغداد)،
وينشرها على **فيسبوك وانستقرام** عبر Buffer. التكلفة: **صفر**.

مبني على نفس هيكل `mody-social`: خطة شهرية على القرص، استئناف من حيث توقف،
ومنع تكرار أي صورة أو جملة عبر الأشهر.

## القاعدة الأولى
**نموذج الصور لا يكتب حرفاً.** كل النص — العربي واللاتيني — يُطبع في Chromium
من HTML/CSS بخط Tajawal مدموج داخل المستند. لهذا لا تخرج حروف مشوّهة أبداً.

**صور المدن حقيقية** من Pexels (رخصة تجارية)، لأن نماذج الصور تشوّه المعالم:
برج غلطة وقلعة أربيل يخرجان خطأً، والمسافر العراقي يعرف مدينته. Cloudflare
Workers AI يُستعمل للخلفيات المجرّدة وحارس النص فقط.

## القوالب الأربعة
| القالب | الشكل | الصور |
|---|---|---|
| `destination` | صورة كاملة + اسم المدينة ضخماً + مسار منقّط | ١ |
| `boarding` | إطار صورة + بطاقة صعود ورقية BGW ✈ IST | ١ |
| `arches` | ثلاث وجهات في قوالب مقوّسة على تدرّج تركوازي | ٣ |
| `fan` | بتلات صور فوق طائرة + الخدمات | ٥ |

نوع اليوم يدور على `TYPE_CYCLE` في `src/lib/compose.mjs`؛ الوجهة تدور
حسب ترتيب النوع لا ترتيب اليوم، وإلا تناوبت مدينتان فقط.

## فلاتر الصور — كلها تعمل على الصورة نفسها لا على وصفها
- **سطوع**: متوسط إضاءة < 92 أو أكثر من 42% أسود → رفض (الصور الليلية تجعل الإعلان قاتماً).
- **تباين**: انحراف معياري < 28 → رفض.
- **تشبّع**: < 20 → رفض (الصور الرمادية لا تبيع سفراً).
- **بصمة إدراكية (DCT 64 بت)**: مسافة هامنغ < 10 من أي صورة سابقة → رفض.
- **حارس الرؤية** (اختياري، Cloudflare): يرفض الصور التي فيها لافتة أو كتابة
  أو أشخاص في المقدمة. يُفعَّل تلقائياً عند وجود حسابين فأكثر.

## الأوامر
```bash
npm run doctor      # فحص المفاتيح والخطوط والموسيقى وffmpeg
npm run generate    # بناء صور الشهر (يستأنف تلقائياً)
npm run reels       # بناء ريلز الشهر
npm run topup       # تعبئة طابور Buffer (--dry-run للتجربة)
npm run preview 24  # إعادة رسم يوم من صوره المحفوظة، بلا شبكة
```

## الأتمتة (GitHub Actions)
| Workflow | التوقيت | العمل |
|---|---|---|
| `generate.yml` | كل ٣ ساعات | يكمل صور الشهر ثم يتوقف في ثوانٍ |
| `reels.yml` | كل ٣ ساعات | يكمل ريلز الشهر |
| `topup.yml` | كل ٣ ساعات | يبقي طابور كل قناة على ٩ منشورات (سقف الخطة المجانية ١٠) |

الوسائط تُحفظ في `posts/` وتُخدَم من GitHub Pages؛ Buffer يجلب الملف
**لحظة النشر**، لذا يفحص `topup` كل رابط بـHEAD قبل الجدولة — رابط ميت
يفشل بصمت بعد أيام.

## الأسرار المطلوبة
| المفتاح | لماذا |
|---|---|
| `PEXELS_API_KEY` | صور المدن |
| `BUFFER_API_KEY` | الجدولة |
| `CF_ACCOUNT_ID` / `CF_API_TOKEN` | خلفيات مولّدة + حارس النص (اختياري) |
| `CF_ACCOUNT_ID_2..5` / `CF_API_TOKEN_2..5` | تدوير الحصة: كل حساب ١٠٬٠٠٠ نيورون يومياً |
| `PAGES_BASE_URL` (متغيّر) | رابط الوسائط العام |

## قواعد ثابتة
- **بلا أسعار** في أي إعلان — الأسعار تتغيّر كل ساعات وتظهر على الموقع فقط.
- **بلا أسعار تأشيرات** إطلاقاً.
- العربية فقط.
- فيسبوك وانستقرام فقط — لا Google Business (وكالة على الإنترنت بلا محل).
